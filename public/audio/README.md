# Audio Files Needed

This directory should contain the following audio files:

## Required Files

1. **rain-light.mp3**
   - Soft, steady rain sound
   - Gentle and calming
   - Loopable (seamless loop)
   - Duration: 20-30 seconds
   - Size: < 500KB

2. **rain-heavy.mp3**
   - Heavier rain with distant thunder rumbles
   - More intense than light rain
   - Thunder should be distant and not startling
   - Loopable (seamless loop)
   - Duration: 20-30 seconds
   - Size: < 500KB

3. **rain-archive.mp3**
   - Muffled, underwater-like rain sound
   - Deeper and quieter
   - Creates "puddle" atmosphere
   - Loopable (seamless loop)
   - Duration: 20-30 seconds
   - Size: < 500KB

4. **release.mp3**
   - Soft, satisfying sound for release action
   - Options: water drop, gentle chime, soft whoosh
   - Short: 1-2 seconds
   - Size: < 100KB

## Download Instructions

1. Visit one of the recommended sources
2. Search for appropriate rain sounds
3. Download MP3 files
4. Rename them to match the names above
5. Place them in this directory

## Tips for Choosing Audio Files

1. **Loopability**: Make sure the start and end match seamlessly
2. **Volume**: Not too loud - ambient background only
3. **Consistency**: All three ambient tracks should sound cohesive
4. **File Size**: Keep files small for fast PWA loading
5. **Quality**: 192kbps or 256kbps MP3 is sufficient

## Testing

After downloading audio files:
1. Test each file in a music player
2. Ensure they loop seamlessly
3. Check volume levels are appropriate
4. Run the app and verify audio works in each mode

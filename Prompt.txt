# Downpour - Comprehensive Vibecoding Prompt

## Overview

Build a mobile PWA called **Downpour** - a minimalist emotional release journaling app. The core philosophy is "dump and go": users write what's weighing on them, release it into the rain, and return to their day. This is not a reflection app. It's a release valve.

The aesthetic is cosy-stormy: the feeling of being safe inside watching rain fall, letting heavy things wash away.

---

## Core Philosophy

- **Release, not reflection.** Users aren't here to analyse or sit with their feelings. They're here to let them fall away.
- **Minimal friction.** Getting words out should feel effortless.
- **Atmospheric but not slow.** The rain theme creates mood without creating delay.
- **The puddle, not the point.** History exists but isn't the focus. The primary action is always release.

---

## Technical Requirements

- **Platform:** Mobile-first Progressive Web App (PWA)
- **Storage:** Local storage only (no accounts for MVP)
- **Responsive:** Optimised for mobile, functional on tablet/desktop
- **Audio:** Ambient rain/thunder sounds (with mute option)
- **Offline capable:** Should work without internet connection

## Screens & User Flow

### 1. Title Screen

**First launch only (before onboarding):**
- App name "Downpour" displayed elegantly
- Subtle rain animation in background
- Gentle ambient rain sound begins
- Tap anywhere or "Begin" button to start onboarding

**Returning users:**
- Skip directly to Home Screen

---

### 2. Onboarding / Tutorial

A guided walkthrough with conceptual introduction. Keep it simple, atmospheric, not overwhelming. 4-5 screens maximum.

**Screen 1 - Concept Introduction:**
- Visual: Gentle rain animation
- Text: "Some things need to fall away."
- Subtle "Continue" or tap to advance

**Screen 2 - Explain the Two Modes:**
- Visual: Show the two cloud states side by side
- Text: "Light clouds for small weights. Heavy clouds for bigger ones."
- Brief visual indication of each cloud type

**Screen 3 - The Release:**
- Visual:示意 text dissolving into rain
- Text: "Write what's here. Then let it go."

**Screen 4 - The Puddle:**
- Visual: Subtle puddle/archive icon
- Text: "Everything lands somewhere. You can look back if you need to."

**Screen 5 - Ready:**
- Text: "That's it. Let it rain."
- Button: "Start" → leads to Home Screen

Tutorial should feel like a gentle introduction, not an instruction manual. Atmospheric, poetic, minimal.

---

### 3. Home Screen

The primary screen. Two entry points representing the two modes.

**Layout:**
- Clean, minimal interface
- Two cloud visuals as tap targets:
  - **Light cloud:** Wispy, lighter, soft edges
  - **Heavy cloud:** Dark, dense, storm-like
- Subtle labels beneath or integrated: "Light" and "Heavy" (or discover through interaction)
- Archive/puddle icon: Small, unobtrusive, bottom corner or similar
- Settings icon: Small, unobtrusive, opposite corner

**Atmosphere:**
- Gentle background animation (slow-moving clouds or soft rain)
- Ambient sound playing (soft rain, adjusts based on last mode used or neutral default)

**Interaction:**
- Tap light cloud → Enter Light Mode writing screen
- Tap heavy cloud → Enter Heavy Mode writing screen
- Tap puddle icon → Open Archive
- Tap settings icon → Open Settings

---

### 4. Writing Screen (Light Mode)

**Entry transition:**
- Brief atmospheric moment (1-2 seconds): rain intensifies slightly, screen settles
- Then input area appears

**Layout:**
- Leading question at top: "What needs to fall away?"
- Large text input area below
- Character counter showing limit (280 characters)
- Emotion tag selector (optional): Horizontal scrollable row or grid of tags
- "Release" button at bottom

**Emotion Tags (all optional):**
- Anxious
- Overwhelmed
- Frustrated
- Sad
- Lonely
- Exhausted
- Angry
- Restless

Tags should be styled as subtle, tappable pills/chips. Tapping selects (visual highlight), tapping again deselects. User can select one or none.

**Atmosphere:**
- Soft, steady rain sound
- Gentle rain animation in background (not distracting)
- Muted, calming color palette

**Interaction:**
- User types their note (max 280 characters)
- Optionally selects an emotion tag
- Taps "Release" button

---

### 5. Writing Screen (Heavy Mode)

Same structure as Light Mode with these differences:

**Atmosphere:**
- Heavier rain sound, distant thunder rumbles
- More intense rain animation
- Slightly darker color palette

**Character limit:** 600 characters

**Entry transition:** Slightly more dramatic atmospheric moment

---

### 6. Release Animation

When user taps "Release":

**Animation sequence:**
1. Text visually dissolves/fragments
2. Text fragments drift downward, absorbed into rain
3. Gentle visual feedback (ripple, fade, or similar)
4. Brief moment of stillness
5. Return to Home Screen (or option to write another)

**Audio:**
- Soft sound accompanying release (raindrop impact, gentle whoosh, or subtle chime)
- Should feel satisfying and final

**Duration:** 2-3 seconds total. Long enough to feel meaningful, short enough to not frustrate.

---

### 7. Archive / Puddle Screen

Accessed via subtle icon on Home Screen.

**Visual concept:** Looking down into collected rainwater. Deep, still, reflective.

**Layout:**
- Header: "Puddle" or simply a back arrow
- Chronological list of past entries (newest first)
- Each entry shows:
  - Date and time
  - Emotion tag (if selected)
  - Mode indicator (light/heavy) - subtle visual like a small cloud icon
  - Preview of text (truncated)
- Tap entry to expand and read full text

**Atmosphere:**
- Darker, deeper color palette
- Subtle water/depth visual effect
- Quieter ambient sound (muffled rain, like being underwater)

**Interaction:**
- Scroll through entries
- Tap to expand/collapse individual entries
- Back button/gesture to return to Home

**Note:** Entries accumulate. No delete function for individual entries (intentional - what's released is released). Users can clear ALL data in Settings if needed.

---

### 8. Settings Screen

Minimal, functional.

**Options:**
- **Sound:** Toggle on/off
- **Clear all data:** Button with confirmation dialog ("This will delete all your entries. This cannot be undone.")
- **Replay tutorial:** Option to view onboarding again
- **About:** Brief app description, version number

## Visual Design Direction

### Overall Aesthetic
- **Minimalist:** Clean, uncluttered, generous whitespace
- **Atmospheric:** Mood comes from subtle animation and color, not decoration
- **Soft:** Rounded corners, gentle transitions, nothing harsh

### Color Palette
- Base: Deep blue-greys, muted teals, soft charcoals
- Light mode accent: Lighter greys, silver, soft white
- Heavy mode accent: Darker slate, deep navy, storm grey
- Text: Off-white or very light grey for contrast
- Consider subtle gradients for depth

### Typography
- Clean, modern sans-serif
- Good readability at various sizes
- Slightly rounded fonts work well with the soft aesthetic
- Consider: Inter, Nunito, Quicksand, or similar

### Iconography
- Simple, line-based icons
- Consistent stroke weight
- Cloud icons for modes should be distinctive but cohesive

### Animations
- Smooth, eased transitions
- Rain: Procedural or looping video/CSS animation
- Keep performant - don't drain battery
- Dissolve effect for text release: Could be particle-based, fade-and-drift, or blur-dissolve

---

## Audio Design Direction

### Ambient Sounds
- **Light mode:** Soft, steady rain. Occasional gentle patter. Peaceful.
- **Heavy mode:** Heavier rainfall, distant thunder rumbles (not startling), more presence.
- **Archive:** Muffled, deeper, like rain heard from underwater or inside.

### UI Sounds
- Release action: Subtle, satisfying sound (soft chime, water drop, gentle whoosh)
- Button taps: Optional subtle feedback sounds
- Keep sounds soft and non-intrusive

### Implementation
- Loopable audio files
- Smooth crossfades between modes
- Respect user's mute toggle
- Consider system silent mode

---

## Data Structure

Each entry should store:

```javascript
{
  id: string,          // Unique identifier
  text: string,        // The journal entry
  mode: 'light' | 'heavy',
  emotion: string | null,  // Selected emotion tag or null
  timestamp: Date,     // When it was released
}
```

Store as array in localStorage. Consider a simple key like `downpour_entries`.

---

## Edge Cases & Details

- **Empty submission:** Don't allow release with no text. Disable button or show gentle prompt.
- **Character limit reached:** Visual indication (counter changes color), prevent further typing.
- **First visit detection:** Check localStorage for onboarding completion flag.
- **Sound autoplay:** May need user interaction before audio can play (browser restrictions). Handle gracefully.
- **Offline:** App should work fully offline since it's local storage only.
- **Long entries in archive:** Truncate preview, expand on tap.

## Summary

Downpour is an emotional release app disguised as a journaling app. The rain metaphor isn't decoration - it's the core interaction model. Users don't "save" entries, they "release" them. The archive is a "puddle," not a "history." Every design choice should reinforce the feeling of letting go.

The experience should feel like:
- Opening the app in a moment of overwhelm
- Being met with calm, atmospheric space
- Choosing how heavy this feels
- Writing without pressure
- Watching it dissolve
- Closing the app lighter than you opened it

Build this with care. It's a small, intimate tool for difficult moments.
